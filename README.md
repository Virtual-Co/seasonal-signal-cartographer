# Seasonal Signal Cartographer

An offline fog-of-war exploration game. Spend eight expeditions uncovering synthetic wildlife sightings as the season changes. Tap the golden suggestion or chart your own route; a seeded random scout explores alongside you.

Open `demo/index.html` in a modern browser. It has no runtime network requests, external libraries, fonts, or assets.

## What is new

This independent educational game fuses point-event exploration inspired by ISBO with seasonal fog-of-war, a scarce expedition budget, and a seeded random scout. It preserves revealed event dots and season tags instead of reducing each patch to one reward. The intensity and acquisition cues are simple illustrative heuristics; they are not a posterior or a scientific performance claim.

**Educational surrogate inspired by ISBO; does not implement INLA, the SPDE mesh, LGCP posterior inference, or the paper's calibrated UCB.**

Paper: Kaichuang Yang, Håvard Rue, and Jakob Zeitler, [ISBO, arXiv:2610.12213](https://arxiv.org/abs/2610.12213). The demo is not endorsed by the authors. No third-party code or assets are used.
